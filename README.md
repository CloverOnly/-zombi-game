# 포유하우스 — 챕터 1 3D 플레이 초안

Windows PC에서 `플레이하기.cmd`를 두 번 누르거나 `index.html`을 Chrome/Edge로 열면 실행됩니다. 3D 라이브러리와 배경 파일은 프로젝트에 포함되어 있어 인터넷 없이도 플레이할 수 있습니다. Poly Haven 무료 API에서 받은 가구 모델과 재질도 로컬에 포함했습니다. 시작 후 차례로 읽으며 외부 서버 응답을 기다리지 않습니다.

2026-10-26 사진 배치 개정: 사용자가 제공한 실제 현관·거실 사진과 방 위치를 표시한 추가 사진을 바탕으로 집 안 구조를 다시 구성했습니다. 사용자가 수정한 도면과 답변에 따라 방 3개와 화장실 2개로 다시 구성했습니다. 소파는 거실 아래쪽 벽 앞에 놓았습니다. 검은 현관문·전신거울·흰 수납장, 벽걸이 TV·커튼·베이지 소파, 냉장고·흰 주방과 식탁을 정돈된 상태로 배치했습니다. 시작 화면의 **집 구조 둘러보기**에서 바로 확인할 수 있습니다. 사진으로 확인한 부분과 추정한 치수는 [배치 기록](PHOTO_LAYOUT.md)에 정리했습니다. 재질 출처는 [실내 자산 기록](assets/INTERIOR_SOURCES.md)에 있습니다.

## 조작

공동현관은 제공된 도면을 기준으로 수정했습니다. 601호와 602호는 같은 벽면에 나란히 있고, 602호에서 나와 오른쪽으로 돌면 601호와 맞은편 계단실이 있습니다. 폭과 길이를 줄인 복도 왼쪽에 603·604호, 끝에 605호가 있습니다. 606호는 복도 끝에서 오른쪽으로 돌아야 보이고 계단실 문과 마주 봅니다. 복도 중간에서 오른쪽으로 돌면 엘리베이터 두 대가 보입니다. 복도 중간의 벽 모서리가 605호 쪽에서 601호가 보이는 시야를 가립니다. 자세한 근거와 추정 범위는 `PHOTO_LAYOUT.md`에 있습니다.

공용 복도의 벽·천장 점무늬를 부드럽게 다듬고 바닥 타일의 결, 벽 아래 그림자, 천장 마감과 따뜻한 조명을 추가했습니다. 화면 해상도에 따라 렌더링 밀도를 조절해 계단 현상을 줄였습니다.

- 시작 화면의 **이웃집 조사부터 이어하기**로 감염자를 처치하고 차키를 챙긴 복도에서 새 이야기를 바로 확인

블로그 사진과 앞서 만든 1인칭 초안의 색·재질·분위기를 참고했습니다. 실제 세대의 정확한 도면과 방 연결은 확인되지 않았으므로 게임용 임시 배치입니다. 플레이 화면은 실시간 3D 공간입니다. 공용 복도의 문과 동·호수는 이야기를 위해 구성했습니다. 동료 합류는 아직 포함하지 않았습니다.

## 복도 장면 진행

1. 시작 화면의 **현관 앞에서 이어하기**를 선택하면 준비물 여섯 개를 챙긴 상태로 시작합니다.
2. E로 현관문을 엽니다. 감염자가 열린 문까지 다가오면 S로 물러나세요. 가만히 있으면 공격을 받아 체력이 줄고 집 안으로 후퇴합니다.
3. 집 안 신발장 앞에서 E를 눌러 문을 열고, 다시 E로 야구방망이를 꺼냅니다.
4. 현관을 다시 열고 나가 왼쪽 클릭 또는 F로 공격합니다. 공격은 기력을 사용하고, 감염자는 세 번 맞으면 쓰러집니다. 감염자가 손을 들면 거리를 벌려 피할 수 있습니다.
5. 이웃집 문을 바라보고 E로 상태를 확인합니다. 604호에서는 E로 대화를 이어갑니다. 이웃은 문을 열지 않으며 2층 주차장의 위치를 알려줍니다. 다섯 집의 단서는 Tab 가방의 기록에서 다시 읽을 수 있습니다.
6. 다섯 집을 확인하고 대화를 마치면 복도 중간에서 오른쪽으로 돌아 엘리베이터로 이동합니다. 문 옆 호출 버튼에 E, 탑승 후 **2** 버튼을 정확히 바라보고 E를 누르면 2층 주차장으로 내려갑니다.
7. 홀에서 주차장으로 나와 **31가 4012** 차량을 찾습니다. M 지도에는 내 차가 노란색으로 표시됩니다. 운전석 쪽에서 E로 잠금을 풀고 문이 열리면 다시 E로 탑승합니다.
8. 운전석에 앉으면 E로 시동을 겁니다. W/S로 전진·후진, A/D로 조향합니다. 오른쪽의 **1층 출구** 표지와 M 지도 점선을 따라 경사로에 진입합니다.
9. 천천히 내려가면 차단기가 자동으로 열립니다. 1층 출입구에서 앞 도로로 나와 골목을 탐색합니다. Space로 완전히 정차한 후 E로 내릴 수 있으며, 차량 문으로 돌아가 E로 다시 탑승할 수 있습니다.
10. 가까이 다가가면 작업복 차림의 감염자들이 쫓아옵니다. 도보에서는 거리를 벌리며 방망이로 대응하고, 차 안에서는 차체 내구도를 살피며 이동합니다.

1층 출입구와 앞마당 탐색도 유지됩니다. 엘리베이터의 **1** 또는 **4** 버튼으로 왕복할 수 있습니다.

이번 확장 구역과 층 배치는 게임 진행을 위한 임시 설계이며 실제 건물의 복도 길이·엘리베이터 위치를 실측한 구조는 아닙니다.

거리 구성 근거는 `../photos/`의 제공 사진 9장과 `../reference-map.png`입니다. 어두운 주차장 외벽·차단기, 도로 양옆 주차, 보도·가로수, 카페 유리창, 편의점 교차로와 옹벽을 참고했습니다. 가려진 구간의 연결과 폭, 확대 주차장 및 2층에서 1층으로 내려오는 경사로의 길이는 플레이를 위한 추정치입니다.

정적 주차장·거리 형상을 같은 재질끼리 묶고, 좀비의 같은 관절에 붙은 부품을 합쳐 렌더링 부담을 줄였습니다. 표면 질감이 있는 형상은 미터 단위 UV를 보존해 병합하며, 나뭇잎은 인스턴스로 그립니다. 차량·차단기·좀비 관절은 독립적으로 움직입니다.
